## GitHub Pages ile Yayımlama

1. Son sürüm HTML dosyasını GitHub deposuna yükleyin ve adını **`index.html`** yapın.
2. **Settings → Pages** bölümünü açın.
3. **Build and deployment → Source** altında **Deploy from a branch** seçeneğini seçin.
4. Dal olarak **`main`**, klasör olarak **`/(root)`** seçin.
5. **Save** düğmesine basın.

Yayımlama tamamlandığında site şu biçimde bir adreste erişilebilir olacaktır:

`https://ayhanbzkrt.github.io/DEPO-ADI/`

Burada `DEPO-ADI` yerine GitHub deposunun adı yazılmalıdır.

Depoda yalnızca `index.html` ve `README.md` dosyalarının bulunması yeterlidir. Ayrıca derleme veya paket kurulumu gerekmez.
